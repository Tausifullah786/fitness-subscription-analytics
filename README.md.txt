# FitnessHub Subscription Analytics

## Project Overview

This project analyzes FitnessHub's customer subscriptions, retention patterns, subscription revenue, and customer acquisition costs using Tableau.

The objective is to understand customer churn, forecast subscription revenue for the next 12 months, and evaluate when customer lifetime value (LTV) recovers customer acquisition cost (CAC).

## Tools Used

- Tableau Public
- Microsoft Excel
- Customer cohort analysis
- Time-series revenue forecasting
- Cumulative LTV and CAC analysis
